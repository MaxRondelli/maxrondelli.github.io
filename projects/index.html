research

  1. TPLP
    From Reasoning to Code: GRPO for Underrepresented Languages
    Federico Pennino, Bianca Raimondi, Massimo Rondelli, Andrea Gurioli, Maurizio Gabbrielli
    Theory and Practice of Logic Programming, 2026 · Python, GRPO, Qwen2.5-Coder, SWI-Prolog
    Summary Details Code Paper arXiv

    Small Qwen2.5-Coder models (0.5B–7B) are trained with Group Relative Policy Optimization to solve GSM8K problems by reasoning and then writing Prolog. Each answer is executed by a live SWI-Prolog interpreter inside the RL loop, and a composite reward scores both logical correctness and output structure, improving reasoning quality and code accuracy on underrepresented languages.

  2. arXiv
    BlenderRAG
    Massimo Rondelli, Francesco Pivi, Maurizio Gabbrielli
    arXiv preprint, 2026 · Python, Blender add-on, RAG (Qdrant), LLMs
    Summary Details Code arXiv Dataset Website

    A Blender add-on that turns a natural-language description into an executable Blender Python script. Retrieval over a curated dataset of 500 expert-validated (text, code, image) examples across 50 object categories raises the compilation success rate from 40.8% to 70.0% and CLIP alignment from 0.41 to 0.77 across four LLMs, with no fine-tuning.

  3. B.Sc. Thesis
    Formula 1 Tyre Strategy Prediction
    Massimo Rondelli
    B.Sc. thesis, University of Bologna, 2023 · Python, FastF1, LSTM / GRU / MLP
    Summary Details Code Paper

    Recurrent and feed-forward networks trained on FastF1 telemetry to predict the best tyre compound for each lap of a Formula 1 race. The GRU reached 51.4% accuracy, against 28.1% for the LSTM, 27.1% for the MLP and 24.5% for a blind classifier.

personal

  1. Computer Vision
    HRNet with Custom Dataset
    Human pose estimation on a custom COCO-style keypoint dataset
    2024 · Python, PyTorch, CUDA, HRNet
    Summary Details Code

    A fork of the official HRNet implementation with the instructions and code changes needed to train it on your own keypoint dataset (COCO format, 12 keypoints instead of 17), plus inference on images and videos. On a 374-image custom dataset, HRNet-W48 (384×288, pretrained) reached 0.568 AP and 0.950 AP50.

  2. Embedded ML
    Human Activity Recognition with LSTM on M5Stack
    On-device activity recognition from IMU data
    2024 · Python, PyTorch, TensorFlow Lite, ESP32 / M5Stack
    Summary Details Code

    An LSTM trained on the UCI Human Activity Recognition dataset to classify six activities (walking, walking upstairs, walking downstairs, sitting, standing, laying). The PyTorch model is converted to TensorFlow Lite and then to a C header, and runs in real time on an M5Stack Gray using its built-in IMU. Test accuracy settles at about 92%.
